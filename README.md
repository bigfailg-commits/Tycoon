# Neon Tycoon

A responsive, browser-based idle business and city-building game. Start with $250, invest in businesses, earn passive income, and grow your empire.

## Play

Once GitHub Pages finishes deploying, play at:
https://bigfailg-commits.github.io/Tycoon/

## Features

- Four businesses to buy and grow: Corner Kiosk, Urban Café, Tech Office, and Skyline Tower.
- Passive income, compounding purchase prices, and offline earnings (up to 8 hours).
- Automation and management upgrades that boost your entire portfolio.
- Profit-collection bonus, milestones, activity log, and optional sound effects.
- Autosave using browser local storage.
- Responsive layout for desktop and mobile.
- No build step or external JavaScript libraries required.

## Project structure

- `index.html` — page structure and game interface
- `styles.css` — responsive styling and illustrated city/business artwork
- `js/game.js` — game logic, economy, upgrades, and save system
- `.github/workflows/static.yml` — GitHub Pages deployment

## Run locally

Open `index.html` in a modern browser, or serve the folder with any static web server. Your progress is saved in the browser on the device you play on.

## Controls

- Click **Buy** to purchase businesses.
- Click **Collect profits** (or press Space) for a bonus payout.
- Buy upgrades to increase income.
- Use the reset icon in the header to start over.
